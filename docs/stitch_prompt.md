# StudyCrack 스티치(Stitch) 디자인 프롬프트 (한국어)

아래 프롬프트는 **현재 레포의 기능 범위**를 최대한 빠짐없이 반영하도록 작성되었습니다.

## 기능 반영 체크리스트(레포 기준)
- 공용/랜딩: 메인, 프로모션 코드 유입, 웰컴/성공 안내, 요금제 소개
- 인증: 로그인, 회원가입, 이메일 인증, 비밀번호 찾기/재설정, 비밀번호 변경
- 학생 핵심: 기초조사서, 성적 입력, 목표 대학 설정, 합격 가능성 분석, 점수 상승 시뮬레이션, 플래너, Pro 리포트
- 결제: 플랜 선택, 프로모션 코드 검증, 일반 결제/예약 결제/이체형 체크아웃, 결제 완료
- 마이페이지: 계정 정보, 이메일 변경 인증, 프로필 이미지, 튜터 정보 확인, 회원 탈퇴
- 문의: Q&A 접수/조회(카테고리 포함)
- 부가: MBTI 다운로드/리포트, 공지/도움 동선
- 역할별: 학생 앱, 튜터 전용 마이페이지, 관리자 웹(운영 백오피스)

## 1) 통합 마스터 프롬프트 (전체 IA + UX + 디자인 시스템)

```text
당신은 모바일 프로덕트 디자이너다.
서비스명은 StudyCrack(스터디크랙)이며, “입시 전략 실행 앱”을 설계한다.

[핵심 제품 원칙]
1) 지금 어디까지 가능한가
2) 어떤 과목을 올려야 가장 유리한가
3) 그래서 지금 무엇을 해야 하는가
이 3가지를 홈에서 즉시 이해하게 설계한다.

[디자인 무드]
- 밝고 정돈된 프리미엄 톤
- 연한 회색 배경 + 흰색 라운드 카드
- 카드 중심 대시보드
- 정보 밀도는 높되, 여백/위계는 명확
- 신뢰감(금융앱 수준의 명료함) + 교육 서비스의 친절함

[플랫폼]
- 모바일 앱 스타일 (iOS/Android 공통)
- 기준 프레임 390x844
- 한국어 UI 카피

[반드시 포함할 기능 IA]
A. 온보딩/인증
- 온보딩
- 로그인
- 회원가입
- 이메일 인증
- 비밀번호 찾기/재설정
- 비밀번호 변경

B. 학생 메인 플로우
- 기초조사서(프로필/전형/학습 맥락)
- 성적 입력(과목별 점수/등급)
- 목표 대학 설정(검색/선택/우선순위)
- 홈 대시보드(현재 상태 + 다음 액션)
- 대학 분석(안정/적정/상향 분류 + 근거)
- 점수 상승 시뮬레이션(과목 조정 시 결과 변화)
- 플래너(주간 실행 계획/체크/첨부)
- Pro 리포트(미리보기/잠금/상세)

C. 결제/전환
- 플랜 비교(Free/Basic/Standard/Pro)
- 프로모션 코드 입력/검증
- 결제 방식 선택(일반 결제/예약 결제/이체형 체크아웃)
- 결제 완료 및 즉시 실행 유도

D. 마이/지원
- 마이페이지(계정/보안/결제내역/설정)
- 이메일 변경 + 인증코드 확인
- 프로필 사진 업로드/삭제
- 튜터 정보 확인
- 회원 탈퇴
- 문의(Q&A) 접수/조회
- MBTI 리포트 다운로드 동선

E. 역할 분리 화면
- 학생용 앱 핵심 화면
- 튜터용 마이페이지(프로필, 정산/입금, 학생 문의 응답)
- 관리자 백오피스(모바일 앱 범위 밖이지만, IA 연결 노드로 표기)

[하단 탭 제안]
- 홈 / 분석 / 플래너 / 리포트 / 마이

[홈 카드 필수 모듈]
1. 합격 가능성 요약 카드 (목표대학 Top3 + 신뢰도)
2. 과목 우선순위 카드 (효자 과목/개선 임팩트)
3. 오늘의 실행 카드 (즉시 할 일 2~4개)
4. 플래너 진행 카드 (주간 달성률/마감 임박)
5. 결제/Pro 인사이트 카드 (락 해제 유도)

[상호 연결 UX 규칙]
- 분석 카드 -> 시뮬레이션으로 1탭 이동
- 시뮬레이션 결과 -> 플래너 액션 자동 생성
- Pro 리포트 잠금 상태 -> 결제 화면으로 자연 연결
- 결제 성공 -> 홈 복귀 시 “지금 할 일 자동 생성” 노출
- 마이페이지 어디서든 문의(Q&A) 접근 가능

[출력 요구 형식]
1) 전체 앱 IA 맵
2) 화면 목록(기능별)
3) 핵심 사용자 흐름(신규/복귀/결제전환)
4) 홈 카드 레이아웃 상세
5) 기능 간 연결 다이어그램
6) 무료체험 -> 유료전환 퍼널
7) 디자인 시스템 토큰(컬러/타이포/간격/라운드/그림자/상태색)
8) 핵심 화면 하이파이 시안 세트
9) 빈 상태/로딩/오류 상태 설계
```

## 3) 홈 화면 전용 프롬프트 (가장 중요)

```text
StudyCrack 홈 대시보드 화면 1장을 설계해줘.

[목표]
첫 5초 안에 사용자가 아래를 이해해야 한다.
- 현재 합격 가능 상태
- 가장 효율적인 과목 개선 포인트
- 오늘 당장 해야 할 실행

[섹션 순서]
1) 사용자 인사 + 현재 플랜 배지(Free/Basic/Standard/Pro)
2) 합격 가능성 요약 카드(목표대학 Top3, 안정/적정/상향)
3) 과목 우선순위 카드(개선 임팩트 순위 + 추천 1순위 강조)
4) 오늘의 실행 카드(체크리스트)
5) 플래너 요약 카드(주간 달성률, 마감 임박)
6) Pro 인사이트 티저(잠금 카드)
7) 문의/도움 바로가기(작은 유틸 카드)

[UX 제약]
- 첫 화면에서 핵심 KPI + 다음 액션이 보여야 함
- 표/복잡 차트보다 요약 카드 우선
- 버튼은 행동 중심 문구 사용
  예: “대학 분석 보기”, “시뮬레이션 실행”, “플래너에 반영”, “Pro 리포트 보기”
```

## 4) 분석 + 시뮬레이션 연동 프롬프트

```text
서로 연결된 2개 화면을 설계해줘.
A. 대학 분석 화면
B. 점수 상승 시뮬레이션 화면

[A. 대학 분석]
- 대학 카드 목록을 안정/적정/상향으로 그룹화
- 카드 정보: 컷라인 근접도, 약점 과목, 전략 코멘트
- 필터 칩: 지역/전형/난이도
- CTA: “이 기준으로 시뮬레이션”

[B. 점수 상승 시뮬레이션]
- 입력: 국어/수학/영어/탐구
- 빠른 조정 버튼(+1/+2/+3 또는 등급 변경)
- 실시간 결과 카드 업데이트
- 변화량 표시: 합격 가능성 변화, 유리한 대학 변화
- CTA: “플래너에 액션 추가”, “리포트에 저장”

[연결 규칙]
- 분석에서 선택한 대학 조건이 시뮬레이션 기본값으로 전달
- 시뮬레이션 확정 결과를 플래너 할 일로 즉시 전환
```

## 7) 이미지 기반 페이지 전용 프롬프트 (주간 전략리포트 / 학습점검 모달)

### 7-1. 주간 전략리포트 화면 프롬프트

```text
스터디크랙의 “주간 전략리포트” 화면을 모바일 앱 스타일로 재구성해줘.

[화면 목적]
- 학생이 이번 주 학습 이행 수준과 취약점 개선 전략을 한 화면에서 이해
- “학생 입력 데이터”와 “컨설턴트 코멘트”를 병렬 비교

[레이아웃]
- 상단: 리포트 헤더
  - 배지: PREMIUM STRATEGY
  - 제목: 스터디크랙 주간 전략리포트
  - 메타 정보: 대상 주차 / 발행일 / 분석 담당자
- 본문 섹션 1: 학습 목표 이행 평가
  - 좌측 카드: 과목별 계획(H), 실제(H), 달성률(%) 테이블
  - 하단: 총 달성률 요약 바 (예: 41.0H / 40.0H)
  - 우측 카드: CONSULTANT 코멘트(문단형)
- 본문 섹션 2: 실전 성취도 & 취약점 분석
  - 좌측 카드: 최근 시험 성적 요약(국수영탐)
  - 우측 카드: 취약 과목 진단 + 개선 포인트 코멘트

[스타일]
- 배경: 아주 옅은 그레이
- 카드: 흰색, 라운드 16~20, 보더 얇게
- 타이포: 제목 강하게, 본문은 가독성 높은 중간 굵기
- 상태색: 달성률 100%는 초록, 주의는 주황, 위험은 레드
- 신뢰감 있는 리포트 톤 (과도한 장식 금지)

[모바일 최적화]
- 데스크탑의 좌우 2열을 모바일에서는 “상단 요약 카드 -> 상세 카드 스택”으로 전환
- 긴 코멘트는 접기/펼치기 제공
- 중요 수치(달성률, 취약 과목)는 칩/배지로 강조

[출력]
- 모바일 하이파이 1안
- 같은 정보 구조의 태블릿 대응 1안
- 컴포넌트 정의(리포트 헤더, 테이블 카드, 코멘트 카드, 상태 배지)
```

### 7-2. 학습점검 모달 Step 1(학습평가) 프롬프트

```text
“26년 4월 4주차 학습점검” 모달의 Step 1(학습평가) 화면을 모바일 앱용으로 설계해줘.

[핵심 UX]
- 모달 상단 고정: 제목 + 닫기 버튼 + Step 탭(1/2)
- 하단 고정: “작성 완료 및 제출” 1차 CTA
- 스크롤 중에도 현재 단계와 제출 CTA가 항상 보이게

[Step 1 구성]
1) 과목별 학습 달성률 입력
- 기본 과목 카드: 국어/수학/영어/탐구
- 입력값: 세부과목명, 계획(H), 실제(H)
- 자동 계산: 달성률 % (실시간)
- 커스텀 과목 추가/삭제

2) 플래너 인증
- 파일 업로드 드롭존(최대 5장)
- 업로드 전/후 상태 UI, 썸네일 리스트

3) 실전 모의고사 응시 여부
- 단일 선택 카드: 미응시 / 교내 / 평가원·교육청 / 사설

4) 최근 2주 학업 추이
- 라디오: 상승 / 유지 / 하락
- 하락 선택 시 조건부 영역 노출
  - 하락 원인(복수 선택): 계획 과다, 실전 감각 저하, 컨디션·건강, 기타
  - 상세 텍스트 입력

[인터랙션]
- 필수값 미입력 시 제출 버튼 비활성 + 인라인 에러
- 숫자 입력은 모바일 숫자 키패드 우선
- 자동 저장 배지(“임시 저장됨”) 표시

[스타일]
- 밝은 회색 배경 + 흰색 카드
- 필수 항목 * 표시와 섹션 아이콘 사용
- 필드 간 간격 크게, 터치 타겟 44px 이상

[출력]
- Step 1 전체 스크롤 시안
- 상태 3종: 기본 / 검증 에러 / 작성 완료
```
