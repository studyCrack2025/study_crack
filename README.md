# StudyCrack (스터디크랙) - 데이터 기반 입시 컨설팅 플랫폼

**StudyCrack**은 수험생과 입시 전문가(Tutor)를 연결해주는 **1:1 맞춤형 입시 컨설팅 및 학습 관리 웹 플랫폼**입니다.

---

## Tech Stack

### Frontend
- **HTML5 / CSS3**: 반응형 웹 디자인 (Mobile, Tablet, Desktop)
- **JavaScript (ES6+)**: Vanilla JS 기반 비동기 통신 및 UI 제어
- **Libraries**: `Chart.js` (데이터 시각화), `PDF.js` & `html2pdf.js` (리포트 PDF 렌더링)

### Backend
- **AWS Serverless**: API Gateway + Lambda 기반 마이크로서비스 아키텍처
- **AWS Cognito**: 사용자 인증 및 토큰 기반 접근 제어
- **AWS DynamoDB**: 유저 프로필, 성적, 결제 내역 등 통합 저장
- **AWS S3**: 플래너 이미지 및 정적 파일 스토리지

### External Integration
- **NICEPAY**: 신용카드 결제 및 Webhook 연동
- **Solapi / AWS SES**: 카카오 알림톡, SMS, 이메일 발송

---

## Key Features

### 학생 서비스
- **입시 분석 및 시뮬레이션**: 환산 점수와 목표 대학 입결 비교, 과목별 점수 상승 시 합격 확률 시뮬레이션
- **주간 학습 점검**: 플래너 및 학습 달성률 입력, 전문가 코칭 리포트 PDF 제공
- **기초조사서**: 성적(정량) 및 진로/가치관(정성) 데이터 입력
- **멤버십 결제**: Basic · Standard · Pro 등급별 차별화 서비스
- **소셜 로그인**: Google · Naver · Kakao 1클릭 로그인/회원가입

### 전문가(튜터) 서비스
- **튜터 전용 마이페이지**: 배정 학생 학습 데이터 확인 및 피드백 리포트 작성 전달

### 관리자 시스템
- **통합 대시보드**: 결제 현황, 신규 가입자, 튜터-학생 매칭 현황 시각화
- **학생 상세 관리**: 성적 추이, 상담 히스토리, 결제 내역 심층 조회 및 관리
- **Q&A 및 알림**: 1:1 문의 응대 및 공지 발송
