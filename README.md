# StudyCrack (스터디크랙)

StudyCrack은 수험생과 튜터를 연결해 데이터 기반 입시 분석, 학습 코칭, 리포트 전달을 지원하는 웹 플랫폼입니다.

---

## 공개 문서 원칙

- 이 문서는 공개 배포 기준으로 작성되며, 비밀키/토큰/내부 식별자/운영 계정 정보는 포함하지 않습니다.
- 상세 운영 절차(배포 파이프라인, 내부 장애 대응 절차 등)는 내부 문서에서 관리합니다.

---

## Tech Stack

### Frontend
- HTML5 / CSS3
- JavaScript (ES6+, Vanilla JS)
- Chart.js, PDF.js, html2pdf.js

### Backend
- AWS Serverless (API Gateway, Lambda)
- AWS Cognito (인증/인가)
- AWS DynamoDB (데이터 저장)
- AWS S3 (파일 스토리지)

### Integrations
- 결제 게이트웨이 연동
- 알림톡/SMS/이메일 발송 연동

---

## Key Features

### 학생
- 목표 대학 분석 및 점수 시뮬레이션
- 주간 학습 점검 및 리포트 확인
- 정성/정량 데이터 입력 및 관리
- 멤버십 결제 및 계정 관리

### 튜터
- 담당 학생 현황 조회
- 피드백/리포트 작성 및 전달
- 특이사항/긴급 이슈 전달

### 관리자
- 튜터-학생 매칭 관리
- 결제/리포트 운영 관리
- 공지/알림 운영

## Versioning Policy

- 기본 버전 정책은 Semantic Versioning (`MAJOR.MINOR.PATCH`)이며, 공개 문서 표기는 `v2.0` 또는 `v2.0.1`처럼 운영 관례에 맞춰 표기할 수 있습니다.
- 변경 이력은 Keep a Changelog 형식(`Added`, `Changed`, `Fixed`)을 따릅니다.
- 날짜 표기는 `YYYY-MM-DD`를 사용합니다.
